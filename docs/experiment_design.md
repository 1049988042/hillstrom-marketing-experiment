# 实验设计与后续分析预案

## 设计和可识别对象

原始发布者称：从过去 12 个月购过物的客户中，随机选择约三分之一收到男装邮件、三分之一收到女装邮件、三分之一不收到邮件；随后观察两周。预期随机分配单位是客户，公开数据每行代表一名客户，但缺少用户 ID，无法独立核实一人一行。`segment` 记录分配/归属，不含实际送达或打开状态，因此后续估计应解释为按公开分组的意向处理效应，而非已送达邮件的效果。

| 角色 | 组别 | 本文件人数 |
| --- | --- | ---: |
| 处理 1 | `Mens E-Mail` | 21,307 |
| 处理 2 | `Womens E-Mail` | 21,387 |
| 对照 | `No E-Mail` | 21,306 |

观察窗口为邮件后的两周；文件没有准确发信日期、个体观察起止日期。目标总体限于该实验的近期购买客户。

## 指标与拟估计效应

主要指标：每个被分配客户的两周 `spend`，包括零消费客户；男装对无邮件、女装对无邮件的均值差为两个主要意向处理效应，单位为每客户美元。次要指标：`visit` 比例、`conversion` 比例及其相对于对照的百分点差。男装对女装的直接差异可以作为预先声明的次级比较。分析不得只筛选访问或购买者后解释为总体因果效应，因为它们是处理后的变量。

异质性分析预先考虑实验前字段 `recency`、`history_segment`、`mens`、`womens`、`zip_code`、`newbie`、`channel`；会限制群体数量、报告各组样本量和不确定性，并处理多重比较。`history_segment` 与 `history` 高度依赖，不应被当作独立信息。定向投放价值未来可比较基于实验前信息的策略与全投/不投，在独立验证样本上评估增量消费；若讨论净收益，需另取得营销成本、毛利及容量约束，当前不能计算真实 ROI。

## 后续必须检查的条件

1. 对实验前变量做组间平衡核查；样本量接近三等分只是表面证据，不证明随机化。
2. 核查缺失、重复记录、异常编码在三组是否不同；无 ID 时只能报告全字段重复，不删除或声称完成用户去重。
3. 确认分配机制、邮件送达、是否交叉接触、两周追踪完整性和一人一行；公开文件无法独立完成这些核查，应保留为识别限制。
4. 估计时明确随机化推断或稳健方差方法、置信区间、零值与偏态消费分布的处理，并预先规定多重比较及群体分析规则。
5. 检查稳定处理、无干扰、处理定义一致等因果识别假设；外推到其他客户、年份或营销渠道需额外证据。

本文件只固定设计，不进行正式检验或业务结论。
