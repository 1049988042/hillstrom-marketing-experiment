# 第四阶段：营销投放策略价值评估与业务决策

## 研究范围与预先冻结的方案

研究问题：对与原实验相似的近期购买客户，全部发送男装邮件（P1）、全部发送女装邮件（P2）、不发送（P0），现有实验数据支持怎样的初步选择？[评估方案](policy_evaluation_plan.md)已在读取验证集消费结果前单独提交，Git 哈希 `8bb40a5ce168841c08046d9fed10a6ccd04920f0`。第三阶段[冻结规则](candidate_rule.json)中的定向候选规则是 `null`，本轮只评估这三种全量策略，没有修改规则或训练模型。

原始 CSV SHA256 为 `0e5893329d8b93cefecc571777672028290ab69865718020c78c7284f291aece`，划分索引 SHA256 为 `eb9dfa4fc8a51fecc801bbfb764c192af95531086431d5349fa80a15c7dc089e`，均与冻结记录一致。验证集 19,200 条，男装 6,392、女装 6,416、无邮件 6,392；探索集 44,800 条。全字段重复记录未删除（验证集 `duplicated()` 后续记录 1,393 条，探索集 4,320 条）。没有唯一用户 ID，不能据此判断重复客户。

估计量是两周**所有被随机分配客户**的人均 `spend`，零消费也计入分母。按冻结方案，对 P1－P0、P2－P0、P1－P2 做双侧 Welch 检验，报告普通 95% CI 和三项同族 Holm p；另以各验证组独立重采样 2,000 次、种子 20261017 给出 Bootstrap 百分位 95% CI。显著性阈值 0.05。普通区间不是多重比较的同时置信区间。

## 假设经济性情景

以下**所有**毛利率与成本均为预设假设，不来自原企业。`m` 为毛利率，`c` 为每客户邮件发送及执行成本，`ΔR` 为邮件相对不发送的人均增量消费：

`P1/P2 增量贡献 = m × ΔR − c`；`P0 增量贡献 = 0`。

## 初步决策建议与不能确认的事项

**统计证据：** 对近期购买客户，两种邮件相对不发送的两周消费点估计为正，验证集方向与第二阶段总体结果一致。男装的点估计消费最高，但验证集不能确认它优于女装。第三阶段四个预定客户特征的整体交互检验均未通过 Holm 校正，故当前不推荐制定基于这些特征的定向发送规则。

**经济性假设：** 若实际毛利与单客户全流程成本接近低成本情景，可将 P1 作为优先试点，并保留 P2 与不发送的随机对照；若成本超过相应门槛，邮件可能不划算。试点选择依据是当前点估计与业务可执行性，不能表述为 P1 已被证明是利润最优策略。若企业希望确认 P1 与 P2 的差别，应事先确定有足够样本量的新实验和经济性指标。

**上线前需要：** 获取真实毛利率、全部发送和创意成本、有效送达、退订或投诉、客户唯一 ID、实际发信与观察时间及长期效果；核验分配与追踪流程，并在当前客户群体上做新的随机试点。公开文件不能独立证明原企业内部随机执行、送达和结果测量，也不能支持实际 ROI、真实利润提升或外推到全部现有客户。
