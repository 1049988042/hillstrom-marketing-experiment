# 与 2008 年 Hillstrom 挑战获奖论文的比较

参考：[Stochastic Solutions (2008), *Hillstrom’s MineThatData Email Analytics Challenge: An Approach Using Uplift Modelling*](https://www.stochasticsolutions.com/pdf/HillstromChallenge.pdf)，核对日期 2026-10-17。下文页码指论文印刷页；PDF 阅读器页码多 1。表 2（页 2）与表 7（页 6）已按页面图像和提取文本交叉核对，数值并非转述第三方摘要。

本项目使用已校验的 64,000 行原始 CSV；本轮只补充描述性分解与固定探索集的事后检验。论文包含模型评分和目标人群排序，本项目没有复现这些部分。

方向与论文讨论一致：当前男装购买者均消费相对对照低 **$0.475776**（论文约 -$0.50），女装高 **$7.892057**（论文约 +$7.89）；男装的访问率与访问后购买率差更大。本项目没有检验购买者条件均值的因果效应，也不沿用论文关于条件消费增加的显著性或促销机制解释。

这些均值水平差异无法仅凭公开 PDF 查明原因；没有论文实际计算脚本或输入版本，不能确定是输入版本、处理口径还是打印误差。当前项目不调整原 CSV、不改历史估计，也不强行使其匹配。

本轮新增的三因素 Shapley 分解是对描述性总差的对称会计分配，不是论文 Uplift 模型的复现，更不是因果中介识别。

## 3. history、recency：目标量与方法不同

论文表 8–9（页 8–9）展示的历史消费和 recency 分箱主要针对**访问率 uplift**，采用其自动分箱与多个随机划分；本轮目标是探索集的**原始人均消费差**，采用用户指定的固定分箱。分界、样本与结果变量不同，不能逐格比较显著性或要求数值相同。

论文页 13 表 12 的历史消费栏为女装消费 Uplift 模型的**平均预测分数**，也不是本项目各历史档直接计算的随机组消费差。因此，本项目高层女装增量点估计较大，只能说其表面方向可与论文部分模型讨论相联系，不能称为复现该模型、证明高价值客户规则或验证论文的投放收益。

本轮实际新结果为：固定 44,800 条探索集，history 原档 1–2 / 3–4 / 5–7 的女装增量分别约 **+$0.4749 / -$0.3501 / +$1.5851**；history 联合 Wald χ²(4)=13.1528、两项 Holm p=0.021106。recency 四档联合 χ²(6)=3.6838、Holm p=0.719379。前者是新的**事后探索线索**，后者未见充分交互证据；高档非零消费稀疏和宽区间限制解释。它们没有获得新的独立验证。

## 4. 可声称的复现范围

本项目实际复现了总体差额基准（按论文精度）、三因素恒等式及条件指标的主要描述性方向；同时记录了均值水平差异。本项目新增了 Shapley 会计分解，以及探索集 history、recency 的 HC3 联合检验。

不声称复现论文的 bagged uplift trees、Qini 排序、高价值人群或负增量人群规则。原四阶段的统计报告、`candidate_rule=null` 和策略评估保持原样。阅读论文之后选择特征的探索，不应包装为观察结果前的确认性研究。
